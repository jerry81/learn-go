# learn-go

This repository is a fast, practical Go syntax/basics starter so you can quickly read and modify production Go code.

## Quick start

```bash
go test ./...
go run ./cmd/learn-go
```

## What to study first

- Variables and functions: `/home/runner/work/learn-go/learn-go/basics/basics.go`
- Common control flow in tests: `/home/runner/work/learn-go/learn-go/basics/basics_test.go`
- Small runnable example app: `/home/runner/work/learn-go/learn-go/cmd/learn-go/main.go`

## Learning checklist

- [x] Function declarations and return values
- [x] `if` statements and boolean logic
- [x] `for` loops over slices
- [x] Maps (`map[string]int`)
- [x] Basic error handling with `error`
- [x] Writing and running Go tests (`go test`)
